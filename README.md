# Clovercraft SMP Issue Tracker

This repository tracks known bugs, suggestions, and required changes for the Clovercraft SMP. Please check the [issues](https://github.com/clovercraft/smp/issues) page for current status.

## Reporting Player Issues

If you are a player on the Clovercraft SMP and would like to report a problem, please visit our [Discord](https://discord.gg/clovercraft) server **#help-desk** channel to open a ticket.

## Note for Staff

This repository is public. Do not put any sensitive data in tickets here.
